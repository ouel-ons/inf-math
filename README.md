# Infinity Maths Club — website starter

A responsive French-language club website built from the supplied Infinity Maths Club logo and event/Instagram images.

## Preview locally
Open `index.html` in a browser. No build step is required.

## Included
- Responsive landing page and navigation
- Club intro, event gallery, open recruitment section and editable bureau roles
- Mini 4×4 Sudoku and a matching-pairs memory game
- Instagram QR code (`assets/instagram-qr.png`) pointing to https://www.instagram.com/infinity_maths_club/
- University logo embed linked to the official Université Abdelmalek Essaâdi site (requires internet access)

## Before publishing
- Replace `Nom à ajouter` and `PHOTO À AJOUTER` placeholders with members' names and portrait images in the `roles`/team rendering section of `index.html`.
- The recruitment form currently prepares a `mailto:` draft and does not store submissions. For a real application workflow, connect it to a form service or backend.
- Confirm event names/dates and add official contact details if desired.
- The university logo loads from Wikimedia Commons; if you prefer a fully offline site, save the official logo as `assets/uae-logo.png` and update the image source in `index.html`.

## Publish free
Upload the folder to GitHub and enable GitHub Pages, or drag the folder into Netlify Drop. Keep `index.html` and the `assets/` folder together.
